# macKali Assets

This directory stores visual assets, previews, screenshots, and artwork for the **macKali** project.

## Directory Structure

```
assets/
├── preview.png        # Master WhiteSur cursor preview
├── screenshots/       # (Planned) Desktop screenshots for presets (Minimal, Balanced, Full)
└── branding/          # (Planned) Project logos and banner art
```

## Asset Guidelines

- **Screenshots**: High-resolution PNG or WebP images showcasing Kali Linux desktop environments with applied macKali presets.
- **Previews**: Component-level previews for cursors, GTK themes, Shell themes, icon sets, and wallpapers.
- **Naming Convention**: Use lowercase kebab-case (e.g., `desktop-minimal-preview.png`, `dock-settings.png`).
