Modular Architecture

Engineered for Kali Linux GNOME

macKali decouples visual styling from system packages, giving you complete macOS elegance without modifying Kali penetration testing tools or core services.

Refined Desktop Appearance

Experience seamless Light and Dark mode transitions with bundled 4K Day/Night abstract wallpapers, genuine WhiteSur vector cursor sets, left-aligned window traffic lights, and Libadwaita color scheme integration.

  • Dual 4K UHD Wallpapers (Sunrise Light & Midnight Dark)
  • WhiteSur macOS cursor theme with scalable HiDPI support
  • Left-hand window traffic light controls (close, minimize, maximize)

macOS-Inspired Dock

Transform Dash to Dock into a centered, bottom-floating dock with intelligent autohide, 48px icons, and running indicators—while strictly preserving all your pinned Kali security tools and favorite application launchers.

  • Centered bottom layout with autohide
  • Strict favorite apps & Kali launcher preservation

Dynamic Extension Engine

Evaluates extensions dynamically against your running GNOME version without hardcoded maximums. Conservative handling ensures untested or unknown versions are never forced.

  • 4-Tier compatibility classification
  • Verified EGO package artifact downloads

Interactive Terminal Wizard (Phase 4A)

The dedicated terminal UI adapts automatically to whiptail, dialog, or clean ANSI text mode. It performs system detection, explains compatibility per extension, offers granular component toggles, and requires explicit user confirmation before applying any changes.

  • Safe dry-run mode and clean cancellation at any point
  • Zero sudo requirement for user customizations

Structured Tiers

Choose Your Installation Preset

macKali defines three structured tiers tailored to performance, daily workflow, and visual nostalgia. Presets are loaded dynamically from repository manifests.

Minimal

Clean, lightweight macOS layout with minimal resource footprint for everyday efficiency.

  • macOS Traffic Light Buttons (Left)
  • Dash to Dock Bottom Centered Layout
  • Dual 4K Dynamic Wallpapers

Dynamic Compatibility

Built for Kali Linux Rolling

macKali does not treat GNOME 50 as a hard ceiling. It evaluates each component independently and adheres to strict safety boundaries.

Extension / Component Classification Target GNOME Safety Behavior
Universal Components (Wallpapers, Cursors, GTK) Verified Compatible GNOME 45 – 51+ Universal user-space assets; never blocked by GNOME version checks.
Dash to Dock (Bottom macOS dock) Verified Compatible GNOME 50.3 Wayland Preserves favorite apps; reverts cleanly via --dock-revert.
Blur My Shell (Frosted glass panel/overview) Verified Compatible GNOME 50.3 Wayland Lightweight pipeline; preserves terminal contrast and readability.
Compiz Magic Lamp (Genie minimize animation) Verified Compatible GNOME 50.3 Wayland Opt-in only; skipped automatically if compatibility is unverified.
Compiz Windows Effect (Wobbly physics) Verified Compatible GNOME 50.3 Wayland Opt-in only; independent disable toggle provided.
Desktop Cube (3D workspace transitions) Experimental Opt-In GNOME 50.3 Wayland Explicit user consent required; never enabled by default.

Component Independence

If an extension is unverified or unsupported on a newer GNOME release, macKali continues installing all other compatible components (wallpapers, cursors, dock configuration). An incompatible extension never blocks the rest of your desktop styling.

Native Validation Preserved

macKali never disables GNOME extension version validation. Unknown upstream versions are classified as COMPATIBILITY_UNKNOWN and are never assumed to be compatible.

Zero System Tampering

macKali never downgrades GNOME, never pins Kali packages, never modifies APT repositories, and never alters penetration testing binaries or system services. Everything runs in user space.

Reversible & Non-Destructive

Every setting change is backed up before modification. You can revert back to your original configuration at any time using ./scripts/restore.sh or perform a clean uninstallation.

Installation

Install macKali Safely

Run the interactive terminal wizard directly on your Kali Linux system. No root permissions required for standard user customization.

git clone https://github.com/realmadede/macKali.git && cd macKali && ./install.sh --interactive
1

Environment Check

The wizard detects your Linux distribution, GNOME version, and Wayland/X11 session.

2

Choose Preset

Select Minimal, Balanced, or Full, and toggle individual visual components.

3

Safety Review

Inspect the compatibility report and create a timestamped configuration backup.

4

Clean Rollback

Cancel at any point before applying, or revert anytime with single-command restore.

Need emergency recovery or rollback? Run ./scripts/restore.sh or switch to TTY (Ctrl+Alt+F3).
