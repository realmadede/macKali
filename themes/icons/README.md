# Icon Themes (Planned for Phase 2)

This directory is reserved for macOS-style icon packs.

## Target Scope
- **Squircle App Icons**: macOS Big Sur / Monterey / Ventura / Sonoma style rounded-rectangle app icons.
- **Folder Icons**: macOS blue folder icons with high-DPI scaling.
- **MIME Type & Symbolic Icons**: System status icons, tray indicators, and file type associations.
- **Kali Linux Tool Icons**: Custom squircle styling for common Kali forensic and penetration testing tools (e.g., Nmap, Wireshark, Burp Suite, Metasploit, Aircrack-ng) to ensure visual coherence.

## Planned Organization
```
themes/icons/
├── WhiteSur-Icons/
└── WhiteSur-Icons-Dark/
```

*Note: In Phase 1, theme assets are not yet installed or bundled. Implementation is scheduled for Phase 2.*
