# GNOME Shell Themes (Planned for Phase 2)

This directory is reserved for macOS-style GNOME Shell themes.

## Target Scope
- **Top Panel**: Translucent or solid menu bar styled after the macOS menu bar.
- **Popups & Menus**: Rounded corners, frosted glass background styling, and native macOS typography spacing.
- **Quick Settings & Calendar**: Styled notification center and control center widgets.
- **Compatibility**: Supports GNOME Shell versions (GNOME 45 through 51) without breaking Kali Linux default indicators.

## Planned Organization
```
themes/shell/
├── WhiteSur-Shell-Light/
└── WhiteSur-Shell-Dark/
```

*Note: In Phase 1, theme assets are not yet installed or bundled. Implementation is scheduled for Phase 2.*
