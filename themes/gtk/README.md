# GTK Themes (Planned for Phase 2)

This directory is reserved for macOS-inspired GTK themes (GTK 3 and GTK 4 / libadwaita styling).

## Target Scope
- **Variants**: Light and Dark modes.
- **Visuals**: macOS window controls (traffic lights on the left: red close, yellow minimize, green maximize), rounded window corners, subtle border outlines, and Monterey/Ventura/Sonoma color palettes.
- **Compatibility**: Kali Linux GNOME Shell sessions, GTK 3 legacy applications, and GTK 4 modern applications.

## Planned Organization
```
themes/gtk/
├── WhiteSur-Light/     # macOS Light GTK theme
├── WhiteSur-Dark/      # macOS Dark GTK theme
└── libadwaita/         # User styles for GNOME 45+ libadwaita compatibility
```

*Note: In Phase 1, theme assets are not yet installed or bundled. Implementation is scheduled for Phase 2.*
